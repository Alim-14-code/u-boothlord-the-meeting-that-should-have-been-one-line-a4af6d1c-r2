The single sentence that could have replaced an entire pointless meeting — an entry for make.fun's The Meeting That Should Have Been One Line bounty ($2, winner-take-all). Round 2 entry: a genuinely different line from round 1 (round 1 was a flat memo; this round has a real punchline about the meeting that could have been an email).

## Entry

> We spent an hour deciding the meeting should have been an email, then scheduled another meeting to send the email.

## How it works

`main.ts` (Node 22, standard library only) reads the line from `entry.txt` and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
